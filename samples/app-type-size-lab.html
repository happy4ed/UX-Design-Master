앱 글자 크기 실측

현재 기기에서 문장을 직접 읽고 최소 크기를 고릅니다. 자로 화면의 50mm 기준선을 맞추면 물리적 크기도 기록할 수 있습니다. 다른 기기나 네이티브 앱의 글꼴 렌더링은 해당 기기에서 다시 확인합니다.

2 · 같은 문장, 다른 크기

실제로 읽기 편한지를 각 줄에서 표시하세요. 13px은 기존 웹 하한과의 비교용이고, 앱의 현재 시작 후보는 14px입니다.

시스템 기본 글꼴 · 파일을 넣으면 두 영역에 함께 적용

아직 평가가 없습니다. 사용 중인 기기에서 각 줄을 읽고 표시하세요.

3 · 실제 화면에서 확인

오른쪽 앱 화면의 가장 작은 글자 크기를 고르고 확대 상태를 바꿉니다. 행 높이와 줄바꿈이 자연스럽게 늘어나는지 직접 보세요.

CSS px 모형

이 화면의 CSS px는 Android의 sp나 iOS의 pt와 동일한 단위라는 뜻이 아닙니다. 최종 앱에서는 시스템 글자 확대를 켜고 같은 글꼴·문구·상태로 다시 검수합니다.

4 · 결정 기록

이 값을 확인 C의 타이포그래피 명세에 붙입니다. 편하게 읽힌 최소 후보와 화면 확대 결과를 함께 기록하세요.
