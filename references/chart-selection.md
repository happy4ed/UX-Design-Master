# 데이터 형태에서 차트 고르기

수치가 있다는 이유로 세 가지 기본 차트 중 하나를 고르지 않는다. 먼저 독자가 판단해야 할 질문, 실제 행, 열의 **의미 역할**, 단위·분모를 적는다. [내부 판별기](../scripts/choose_chart.mjs)는 데이터 구조와 과업을 함께 검사해 주력·대안·제약을 제안한다. `--goal`은 이전의 11가지 목적별 빠른 후보용이며 데이터 적합성 검사는 `--input`에서 한다.

## 사용자 제공 차트 9종

2026-10-27 제공된 Threads 영상에서 **파이·도넛·퍼널·와플·트리맵·선버스트·폭포·파레토·마리메코** 9종을 확인했다. [내부 차트 KB](../knowledge/thread-chart-types.json)에 각 유형의 필수 데이터, 적합한 질문, 피할 조건, 대안, 내부 렌더러 연결 상태를 넣었다. 게시물의 예시를 그대로 복제한 규칙이 아니라 데이터 의미에 따라 재해석한 선택 규칙이다.

| 차트 | 주로 맞는 데이터·질문 | 채택 전 확인 |
| --- | --- | --- |
| 파이·도넛 | 소수 범주의 한 시점 전체 비율 | 같은 분모·양수·합계. 중앙 총계가 필요하면 도넛, 없으면 파이 |
| 와플 | 전체 중 비율을 일정한 칸 단위로 읽기 | 칸 수와 반올림으로 잃는 정밀도 |
| 트리맵 | 여러 부분 또는 계층의 상대 면적 | 값의 합산 가능성·작은 라벨 |
| 퍼널 | 같은 집단의 단계별 잔존·이탈 | 순서·동일 코호트·비증가·분모 |
| 선버스트 | 부모·자식의 여러 단계 구성 | 루트·순환·부모값 중복 집계 |
| 폭포 | 시작값에서 양·음 변화가 끝값에 미친 영향 | 시작+증감=끝값 |
| 파레토 | 상위 범주가 전체에 얼마나 기여하는가 | 양수 가산값·내림차순·누적분모; 80/20을 결론으로 가정하지 않기 |
| 마리메코 | 그룹 크기와 그룹 안의 구성비를 동시에 보기 | 두 범주 축·완전한 교차값·폭/높이의 다른 분모 |

도넛·트리맵·폭포는 기존 내부 SVG 문법에 연결된다. 나머지는 **선택 지식**이며 현재 전용 렌더러가 없다. 판별기가 `renderer: null`을 명시하므로 지원하지 않는 렌더를 지원한다고 주장하지 않는다. 필요할 때 내부 렌더러를 구현·검증하거나 의미를 보존하는 막대·표 등의 대안을 선택한다.

## 판별기 입력

`rows`에는 실제 데이터 행을 넣고 `roles`에서 열의 의미를 지정한다. `task`는 독자가 하고 싶은 판단이다. `task`가 없으면 형태상 가능한 후보만 반환하고 결정을 보류한다.

```bash
node scripts/choose_chart.mjs --list
node scripts/choose_chart.mjs --goal cumulative
node scripts/choose_chart.mjs --input assets/chart-selection-example.json
```

`roles`는 `category`, `group`, `value`, `stage`, `parent`, `delta`, `time`, `x`, `y`를 필요에 따라 쓴다. 단계 이탈에는 `task: "attrition"`, `sameCohort: true`가 필요하다. 시작값과 증감에는 `startValue`, 선택적으로 `endValue`를 둔다. 구성비에는 `partWhole: true`와 실제 분모를 확인하고, 중앙 총계를 강조할 때 `showTotal`, 단위 칸이 중요할 때 `unitGrid`를 쓴다. 두 범주 구성은 `task: "two-way-mix"`와 완전한 교차 행이 필요하다. [입력 예제](../assets/chart-selection-example.json)를 참고한다.

```bash
node tests/test_chart_selector.mjs
```

판별기는 자료가 규칙을 충족해도 `provisional`로 표시한다. 실제 값·단위·변동 범위·범주 수를 적용한 SVG와 표를 함께 보고 최종 유형을 정한다. 합계 불일치·퍼널 단계 증가·마리메코 빈 셀·계층 순환은 경고를 해결하기 전까지 해당 차트를 쓰지 않는다. 결론이 검증된 경우 제목은 `매출 추이`보다 `2분기 이후 월매출 증가가 둔화됨`처럼 읽을 이유를 말한다. 근거가 부족하면 결론을 꾸미지 말고 질문형 또는 중립 제목을 쓴다. 지도 문법은 현재 내부 렌더러에 없으므로 지리 값은 표나 막대 등 적합한 대안으로 검토한다.
