# 폰트 선정과 실제 로딩 검수

[내부 후보 목록 28종과 조합 12종](../knowledge/font-families.json)을 `매체·언어·정보 밀도·목소리`로 거른다. 이름이나 인기만으로 정하지 않는다. 한글·영문·아랍어가 섞이는 실제 문장, 숫자·문장 부호, 굵기, 줄높이, 폴백을 같은 대표 화면에서 비교한다. 목록은 후보 지식이며 폰트 파일을 포함하지 않는다.

`python3 scripts/query_fonts.py --context app-ui --script ko`로 후보를 조회한다. `--installed-only`는 현재 시스템에서 정확한 패밀리 이름이 설치된 후보만 보여준다. 결과에 `installed: false`가 나오면 **해당 서체로 렌더했다고 주장하지 않는다.** 실제 프로젝트에는 사용자가 제공한 파일이나 합법적으로 확보한 폰트를 연결한 뒤 브라우저 네트워크·computed font·글리프·줄바꿈을 검수한다.

`python3 scripts/build_font_preview.py --out samples/font-selection-review.html`로 오프라인 비교 화면을 만든다. 정확한 이름으로 설치된 서체만 실제 서체로 표시하고, 나머지는 파일 미연결 상태로 구분한다. 문구·사용 맥락·문자권을 바꾸어 비교한다. 미연결 후보의 샘플을 해당 서체의 증거로 해석하지 않는다.

폰트 선정 표에는 최소 `본문/제목/숫자/코드/RTL, 크기·굵기·행간·자간, 실제 로딩 상태, 폴백, 긴 문구에서의 폭 변화`를 기록한다. 한글 본문과 영어 표제를 다른 서체로 조합할 때 기준선·x-height·자간이 자연스러운지 실물 렌더에서 본다. 아랍어는 RTL 문단과 숫자 방향을 따로 확인한다. 폰트 교체가 생기면 [한글 줄바꿈 검사](korean-wrap.md)와 전체 화면 정렬 검수를 다시 수행한다.

앱의 최소 글자 크기를 정할 때는 후보 서체 파일을 [실제 기기 글자 크기 실측 화면](../samples/app-type-size-lab.html)에 연결해 같은 문장을 비교한다. 자 보정으로 물리 크기를 기록하고 기본·150%·200% 확대의 대표 화면을 확인한다. [확정 계약](app-type-size-calibration.md)의 14 시작 기준과 네이티브 앱 재검증 범위를 따른다.
