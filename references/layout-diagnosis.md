# 렌더 증상 진단

[내부 진단 사전 20개](../knowledge/layout-diagnoses.json)는 화면의 증상을 `관찰 → 측정 → 원인 후보 → 수정 → 같은 조건 재검증`으로 연결한다. `python3 scripts/diagnose_layout.py "모션"`처럼 검색할 수 있다. 문자열 일치가 원인 판정은 아니다. 실제 브라우저/앱의 계산된 값과 두 시점의 상태를 본다.

특히 모션이 안 보일 때는 CSS 선언 수나 효과 목록만 세지 않는다. 실행 중인 animation, 대상의 시작·중간·끝 값, 시스템의 움직임 감소 설정, 레이어 가림, 이벤트의 상태 변경을 각각 확인한다. 검토용 시연에서 설정을 무시할 때는 명시적인 컨트롤을 제공하고 실제 제품의 접근성 정책과 분리한다.

텍스트·정렬 문제는 원인을 하나로 가정하지 않는다. 글꼴 폴백, 콘텐츠 길이, 부모의 min-width, overflow clip, 인접 요소의 hit 영역이 동시에 영향을 줄 수 있다. 수정 뒤 초기·포화, 좁은 폭·긴 번역, RTL 조건을 해당 화면에서 다시 확인한다.
