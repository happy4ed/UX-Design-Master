## F. 패턴

하위 화면+스위치 행, 목록/상세, 설정 묶음, 필터 선택, 확인, 빈/로딩/오류, 다중 선택 최대치는 디지털 패턴이다. 모두 실물 장비의 원형이 **미확인**이므로 해당 제품의 실제 과업과 플랫폼 관례를 먼저 정하고 물성만 제한적으로 적용한다. 물리 장비가 불가능한 정보량을 억지로 작은 VFD 창에 넣지 않는다.

## G. 인터랙션

푸시 버튼의 눌림, 노브 회전, 슬라이더 끌기는 실물 동영상 근거가 없어 동작의 정확한 이동량·시간·이징·진동은 **미확인**이다. 디지털 구현에서 누름 피드백·화면 전환·시트/대화상자 등장·드래그·취소를 별도 설계하고 원본 움직임이라고 부르지 않는다. 키보드·터치 대체와 모션 감소 모드를 지원한다.

## H. 문구 관례

실물의 짧은 대문자/소문자 각인은 물성 참고다. 디지털 화면의 제목·버튼은 현재 기능이 바로 읽히는 한국어로 쓰고 단위(dB·초·%)를 값과 함께 둔다. 작은 보조 각인을 그대로 축소해 읽기 어려운 UI로 만들지 않는다.

## I. 해도 되는 것 / 안 되는 것

1. 금속 패널과 노브를 쓸 때는 **같은 모델의 광원·소재**를 따르며 마구 섞지 않는다(S1/S2).
2. 실물 VFD는 정보를 표현하는 표면의 근거이지 텍스트 입력창의 공식형이 아니다(S3).
3. 실물 5030 키와 MODEL 40n 노브는 다른 장비다. 하나의 제품 사진처럼 합성해 놓고 원형 제품이라고 하지 않는다(S1/S3).
4. 스크린샷에서 측정한 색은 카메라·광원 색이 섞였다. 제조사 표준색이나 가이드 공식 토큰이라고 부르지 않는다(S3).

## J. 접근성 덮어쓰기

디지털 조작 영역 **최소 48×48**, 조작 글자 **최소 14**, 텍스트·아이콘은 실제 바탕에서 대비를 재검사한다. 실물의 작은 각인·버튼 모양은 외형만 참고하고 투명 조작 영역이나 큰 재배치를 적용한다. 전달 실측의 `보조 라벨 0.55배`를 앱에 그대로 적용하지 않는다. 바꾼 값의 목록: 작은 실물 라벨→14 이상(제안), 물리 버튼 실측 미확인→48 이상(접근성 하한); 정확한 전후 px는 검증 렌더에서 기록한다.

## K. 미확인 목록

### K.2. guess 교체 기록

[기본 레퍼런스](../../samples/style-guess-books.html?style=skeuo-audio-hifi)의 C.1 토큰·E.4 부품·G.1 모션은 `목재 외함·금속 패널·물리 스위치의 무게`을 구현한 `guess`이다. A는 스타일 신원, B는 실제 출처만 기록하고 추론으로 출처를 꾸며내지 않는다. D/F/H/I/J는 이 기본 레퍼런스를 기기·과업·문구·접근성에 맞게 재배치·확장하는 계약이다. L의 내부 렌더 PASS는 원본 일치 판정이 아니다. 새 원본에서 같은 부품과 상태를 발견하면 원본 화면의 값·프레임을 실측 → 현재 guess와 차이 기록 → 코드와 책 수정 → 다시 렌더 검수 → 해당 항목의 `guess` 태그 제거 순으로 갱신한다.
