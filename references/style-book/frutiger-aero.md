## F. 패턴

하위 화면+스위치 행, 목록/상세, 설정 묶음, 필터 고르기, 확인, 빈/로딩/오류, 다중 선택과 최대치는 실제 제품의 과업으로 먼저 정의한다. 이 자유 스타일의 원본 사례에서 해당 패턴이 보이지 않으면 `미확인`으로 기록하고 플랫폼 관례를 우선한다.

## G. 인터랙션

누름 피드백·화면 전환·시트/대화상자 등장·끌기·진동은 실제 서비스에서 재생 확인 전 `미확인`이다. 가안에서 선택하면 반사·광택 변화는 입력 피드백을 설명할 때만라는 디자인 제안으로 표시하고, 키보드·터치 대체와 모션 감소를 검수한다.

## H. 문구 관례

버튼·제목은 과업을 짧게 명명한다. 단위와 상태는 실제 데이터에 맞춘다. 스타일 효과를 설명하려고 같은 의미를 반복하지 않는다. 대소문자·동사형의 원본 관례는 미확인이다.

## I. 해도 되는 것 / 안 되는 것

1. 유리·하늘·물의 풍부한 시각층을 정보 영역과 구분한다 (제안, 기존 내부 스타일북).
2. 향수 표현을 위한 물방울·광택이 텍스트를 가리지 않게 한다 (제안, 검증 필요).
3. 실제 사례의 한 장면에서 보이지 않는 슬라이더·시트·다크 토큰을 계열의 공식 규칙으로 주장하지 않는다.

## J. 접근성 덮어쓰기

모바일 조작 영역 최소 48×48, 조작 글자 최소 14, 텍스트·아이콘·상태는 실제 바탕에서 명암비 실측. 원본 서비스에서 작은 컨트롤이 보이면 원본값과 변경값을 렌더별로 적는다. 현재 바꾼 값 목록: 원본 컴포넌트 실측 미확인 → 접근성 48/14 가안 제안.
