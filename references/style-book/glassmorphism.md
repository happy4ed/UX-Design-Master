세 사례는 각각 **Acrylic / visionOS glass / Liquid Glass**로 구현 방식이 다르다. 공통 관찰은 `콘텐츠 위에 떠 있는 투명한 기능 층`, `배경과 전경의 관계`, `대비를 위한 불투명 대체`다. 세 제품의 R·블러·색 값을 하나의 범용 정답으로 합치지 않는다. 특정 제품을 복제할 때는 해당 플랫폼 가이드를 별도 조사한다. 이미지 표본 원본을 직접 받아 픽셀로 잰 작업은 `NOT_RUN`이며 표본 수는 3개 서비스의 문서 사례다.

측정 시 같은 픽셀 크기·테마로 캡처하고 유리 바깥/안쪽 같은 지점의 5×5 중앙값을 잰다. 불투명도는 바탕색과 합성해 역산한다. blur 반경은 경계 고주파의 감쇠를 비교하고, R은 45° 경계점 원 맞춤으로 오차를 남긴다. 현재 숫자는 모두 `제안`이다.

## E.1. 글꼴·아이콘·슬라이더 결정

이 표는 컴포넌트별 구분이 누락되지 않도록 한 적용 계약이다. `제안`은 시연용 방향이며 원본 재현값이 아니다. 폰/폴드와 라이트/다크에서 각 부품의 기본·누름·포커스·끌기 상태를 따로 확인한다.

| 부품 | 형태·사용 규칙 | 근거 등급 | 상세 근거 |
|---|---|---|---|
| 글꼴 | 중립 산세리프, 투명층 위 대비를 우선 | 제안 | glassmorphism.md C/E |
| 아이콘 | 얇은 윤곽 기호와 솔리드 활성 상태 | 제안 | glassmorphism.md C/E |
| 재생 위치 | 불투명 값 표시와 작은 윤곽 썸; 발광 썸은 근거 없음 | 제안 | glassmorphism.md C/E |
| 음량 | 유리층 아래 대비가 유지되는 솔리드 트랙 | 제안 | glassmorphism.md C/E |

시연 SVG·CSS의 실제 속성은 [기준 화면](../../samples/style-book-reference-screen.html)에서 확인한다. 근거 없는 시연값은 이 가이드의 원본값으로 승격하지 않는다.

## G. 인터랙션

누름은 시각·조작 영역이 함께 피드백한다. 화면 이동에서는 기능층이 콘텐츠를 가리는 순간과 새 콘텐츠가 나타나는 순서를 정한다. 시트·대화상자는 배경 scrim과 닫힘 복구를 함께 시험한다. 끌기 컨트롤은 손가락 아래 값의 연속성과 종단을 확인한다. 진동은 플랫폼 지원과 의미가 확정될 때만 쓴다. 시간·이징은 모두 `미확인`, 제품 프로토타입에서 결정한다(출처 G1–G3, 파생).

### G.1. 기본 모션북 — guess 구현

## H. 문구 관례

제목은 화면 역할을 짧게 쓰고, 투명 배경 위 문구는 실제 이미지/색 전부에서 판독성을 검사한다. 버튼·단위는 대상 제품 명세를 따른다. 유리 효과 설명을 사용자가 볼 문구로 넣지 않는다(제안).

## I. 해도 되는 것 / 안 되는 것

1. 임시 메뉴·도구막대에만 필요한 정도의 반투명 층을 사용한다 / 본문 전체를 여러 겹의 유리 카드로 덮지 않는다(G1,G3).
2. 투명 효과가 꺼져도 불투명 대체 면으로 내용이 읽히게 한다 / 블러를 조작 가능성의 유일한 단서로 쓰지 않는다(G1).
3. 배경색·사진이 바뀌는 모든 상태의 대비를 실측한다 / 유리의 고정 HEX 하나가 어떤 배경에도 통한다고 가정하지 않는다(G1,G3).
4. Glassmorphism을 특정 플랫폼 정본으로 표시하지 않는다. One UI, iOS, Windows는 각 가이드를 따로 적용한다(파생 G1–G3).

### K.2. guess 교체 기록

[기본 레퍼런스](../../samples/style-guess-books.html?style=glassmorphism)의 C.1 토큰·E.4 부품·G.1 모션은 `뒤 배경이 보이는 투명 층과 얇은 경계광`을 구현한 `guess`이다. A는 스타일 신원, B는 실제 출처만 기록하고 추론으로 출처를 꾸며내지 않는다. D/F/H/I/J는 이 기본 레퍼런스를 기기·과업·문구·접근성에 맞게 재배치·확장하는 계약이다. L의 내부 렌더 PASS는 원본 일치 판정이 아니다. 새 원본에서 같은 부품과 상태를 발견하면 원본 화면의 값·프레임을 실측 → 현재 guess와 차이 기록 → 코드와 책 수정 → 다시 렌더 검수 → 해당 항목의 `guess` 태그 제거 순으로 갱신한다.

## L. 검증 렌더
