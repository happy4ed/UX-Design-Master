# Material 3 Expressive — Compose 기준

## A. 신원

| 항목 | 값 |
|---|---|
| 표시 이름 / ID | Material 3 Expressive / `material-3-expressive` |
| 분류 | 플랫폼 |
| 계열·기원 | Google Material 3; Android Jetpack Compose의 Expressive 확장 |
| 대상 버전 | AndroidX Compose Material 3 토큰 커밋 `160825094a81825468a95b115bfb1b541e549856` 및 해당 Compose 컴포넌트. Android Views의 MDC 값과 혼합하지 않음 |
| 가이드 버전 / 확인일 | 0.1.0 / 2026-11-05 |
| 재현 범위 | 미디어 리모컨 기준 화면. 제품 색은 예시 시드 `#CDB17B`의 Tonal Spot 계열이며 플랫폼의 고정 브랜드 색이 아님 |

**사용 조건.** 실제 Android/Compose 화면을 설계할 때 우선한다. 웹에서 이 스타일을 차용할 때는 `Material 3 Expressive에서 파생한 웹안`이라고 표기한다. 모든 시드 색과 컴포넌트 치수는 Compose 버전을 명시해야 한다. 토큰에 없는 배치값은 `제안`으로 분리한다.

**표본 수.** 이 가이드에 숫자로 기입한 직접 확인 표본은 M1의 Slider·MediumIconButton·SearchBar 토큰 3파일과 M5의 미디어 기준 부품 10종이다. 독립 실기기 캡처를 새로 측정한 표본은 0장이다. 따라서 이 파일의 `실측`은 픽셀 캡처 실측이 아니라 M5의 선행 조사값을 인용할 때에만 쓴다. 본 가이드에서 공식 토큰과 실제 화면 픽셀의 차이는 아직 검증하지 않았다.

**환산.** M1의 값은 dp라서 픽셀 역산이 필요 없다. 제품 캡처를 추가하면 원본 px·기기 밀도·텍스트 배율을 같이 기록하고 `px ÷ density = dp`로 환산한다. 색은 sRGB 5×5 중앙값과 압축 오차, 반투명 표면은 바탕색과 상태층을 분리해 기록한다. 곡률은 ShapeKeyTokens의 공식 값이 우선이며, 캡처만 있으면 45° 지점과 기준 원 맞춤의 오차를 기입한다. 폰트는 실제 글꼴과 접근성 확대 설정을 먼저 확인한다.

## E. 컴포넌트 명세

각 행은 `역할/사용 조건 · 해부 · 크기/상태 · 조작/모션 · 근거/바꾼 것/미확인` 순서다. **미확인 수치는 공식 스타일처럼 구현하지 않는다.** 보이는 컨트롤이 48dp 미만이면 접근성 조작 영역을 투명하게 48dp까지 넓힌다(J). 모든 행에 포커스·비활성·선택 상태를 화면에서 확인한다. 모션 수치는 이 버전에서 미확인이다.

## G. 인터랙션

누름은 해당 Compose 컴포넌트의 상태층·형상 변화를 따른다. Medium icon button의 round→`CornerMedium` 누름과 Slider 4→2dp 손잡이 변화는 M1 공식 값이다. 화면 전환·시트/대화상자 등장·끌기 속도·진동의 **시간과 곡선은 미확인**이며 이 가이드의 필수 토큰처럼 쓰지 않는다. 실제 프로토타입에서 탭, 느린/빠른 끌기, 키보드, 끝값, 취소, 모션 감소를 재생·검수하고 제품 선택 값을 따로 기록한다. 진동은 기기 지원과 사용자 설정을 확인한다.

### G.1. 기본 모션북 — guess 구현

이 계열의 알려진 시각 원리 `역할에 따른 형태 차이와 분명한 상태 변화`에서 `형태 변화 뒤 탄성 정착`을 추론했다. 원본 동영상이 없어도 시연을 구현한다. 원본 움직임이라고 주장하지 않으며 나중에 실제 영상이 확인되면 궤적·축·중간 프레임·정착을 비교하고 `guess`를 제거하거나 수정한다.

|---|---|---|---|---|---|---|
| 주 행동 눌림 | 버튼 | 탭/클릭 | 떠 있거나 기본인 조작 → 눌린 조작 → 정착 | 형태 변화 뒤 탄성 정착 · 420ms · `cubic-bezier(.2,0,0,1)` | 움직임 없이 끝 상태 즉시 표시 | `guess` · [재생](../../samples/style-guess-books.html?style=material-3-expressive#motion-demo) |

모든 시연은 중단·역전·반복 클릭에서 상태와 시각이 어긋나지 않아야 한다. 실제 제품의 시간은 대상 크기·맥락·기기에서 재측정하며 이 표의 값은 기본 샘플값이다.

## H. 문구 관례

버튼은 결과를 예측할 수 있는 짧은 동사·목적어를 쓴다. 화면 제목은 화면 역할을 짧게 쓴다. 단위·시간·값 형식은 제품 데이터 사양에서 검증한다. 대문자/소문자, 한국어 조사, 말줄임 규칙은 Material 고정 토큰으로 확인되지 않았으므로 제품 언어 규칙을 별도 둔다. 미디어 시연의 길이·제목·장르를 임의 생성하지 않는다.

## I. 해도 되는 것 / 안 되는 것

1. **가능:** 공식 `ColorScheme` 역할과 컴포넌트 토큰을 연결한다. **금지:** 다크 시드 색을 One UI의 고정 블루처럼 플랫폼 고유색이라 부른다. 근거 M4·M5.
2. **가능:** 시각 아이콘 40dp를 48dp 조작 영역으로 감싼다. **금지:** 시각 크기와 조작 영역을 같은 것으로 간주한다. 근거 M1 Small의 M5 조사와 J의 접근성 규칙.
3. **가능:** Slider의 트랙·손잡이·끝 점을 M1의 현행 Compose 수치로 그린다. **금지:** 구형 얇은 선형 슬라이더나 거대한 원형 thumb를 Material 3 Expressive의 현행 기본이라고 주장한다. 근거 M1 SliderTokens.
4. **가능:** 검색이 화면의 주요 과업일 때 SearchBar를 쓴다. **금지:** 모든 입력을 SearchBar로 대체한다. 근거 M3 SearchBar.
5. **가능:** assist와 filter 칩의 목적을 구분한다. **금지:** 수행 가능한 명령을 선택 필터처럼 보이게 한다. 근거 M3 Chip.

### K.2. guess 교체 기록

[기본 레퍼런스](../../samples/style-guess-books.html?style=material-3-expressive)의 C.1 토큰·E.4 부품·G.1 모션은 `역할에 따른 형태 차이와 분명한 상태 변화`을 구현한 `guess`이다. A는 스타일 신원, B는 실제 출처만 기록하고 추론으로 출처를 꾸며내지 않는다. D/F/H/I/J는 이 기본 레퍼런스를 기기·과업·문구·접근성에 맞게 재배치·확장하는 계약이다. L의 내부 렌더 PASS는 원본 일치 판정이 아니다. 새 원본에서 같은 부품과 상태를 발견하면 원본 화면의 값·프레임을 실측 → 현재 guess와 차이 기록 → 코드와 책 수정 → 다시 렌더 검수 → 해당 항목의 `guess` 태그 제거 순으로 갱신한다.

## L. 검증 렌더

기준 화면: 미디어 리모컨 메인(앱바·카드·포스터·재생·재생 위치·음량 [− 막대 +]·검색·칩·목록 행). **렌더 경로: 미작성 (`NOT_RUN`)**. **자동 실측 결과: 미작성 (`NOT_RUN`)**. 외부 원본 캡처는 스킬에 저장하지 않는다. 실행자가 폰·폴드 × 라이트·다크 네 조합을 실제로 렌더한 뒤 경로와 조작 영역·글자·여백·넘침 실측을 여기에 연결한다. 이 상태에서 가이드를 플랫폼 재현 검증 완료라고 부르지 않는다.
