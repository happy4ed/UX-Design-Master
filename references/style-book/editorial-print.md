## E.1. 글꼴·아이콘·슬라이더 결정

이 표는 컴포넌트별 구분이 누락되지 않도록 한 적용 계약이다. `제안`은 시연용 방향이며 원본 재현값이 아니다. 폰/폴드와 라이트/다크에서 각 부품의 기본·누름·포커스·끌기 상태를 따로 확인한다.

| 부품 | 형태·사용 규칙 | 근거 등급 | 상세 근거 |
|---|---|---|---|
| 글꼴 | 제목은 세리프, 조작과 본문은 읽기 쉬운 산세리프 | 제안 | editorial-print.md C/E |
| 아이콘 | 가는 인쇄선 기호, 작은 시각 크기와 48px 히트 영역 분리 | 제안 | editorial-print.md C/E |
| 재생 위치 | 눈금 같은 가는 선과 얇은 수직 마커 | 제안 | editorial-print.md C/E |
| 음량 | 한 줄 눈금으로 처리하고 수치 병기 | 제안 | editorial-print.md C/E |

시연 SVG·CSS의 실제 속성은 [기준 화면](../../samples/style-book-reference-screen.html)에서 확인한다. 근거 없는 시연값은 이 가이드의 원본값으로 승격하지 않는다.

### E.2. 컴포넌트별 형태·상태·모션 변환

색 토큰만 바꿔 스타일을 적용했다고 판정하지 않는다. 아래는 [시연용 변환표](component-expression.json)의 기능형 **설계 가설**이다. 원본 사례 B절에서 확인된 성격과 E절의 부품 제안을 분리한다. 실제 원본 부품의 형상·누름·선택·모션을 확인하기 전에는 원본 일치로 쓰지 않는다. 같은 콘텐츠로 [13개 역할 보드](../../samples/style-book-component-board.html)에서 확인한다.

## F. 패턴

하위 화면+스위치 행, 목록|상세, 설정 묶음, 필터 고르기, 확인, 빈/로딩/오류, 여러 개 고르기의 최대 상태를 **기사 읽기 흐름을 깨지 않게** 설계한다. 피드/기사에서 이미지·제목·요약·크레딧의 계층을 고정하고, 보조 제어는 본문 영역 바깥으로 둔다. 기고/광고/후원은 기사와 시각적으로 분리한다. E1~E3의 가변 프로모션을 보편적 구조로 복제하지 않는다.

## G. 인터랙션

누름은 글자·밑줄·룰·색 변화 중 역할에 맞는 축을 고른다. 화면 전환은 읽던 위치와 스크롤을 보존한다. 시트/대화상자는 기사 뒤에 떠서 닫으면 원래 문맥으로 돌아간다. 오디오 재생 위치 끌기는 손잡이와 시간 피드백을 제공한다. 진동은 매체/기기별 선택. E1~E3의 실제 동작 시간·이징은 미측정이라 C의 시간은 제안이다.

## H. 문구 관례

기사 제목은 내용을 정확히 말하고, 섹션 라벨·저자·날짜·읽는 시간을 별도 계위로 둔다. 버튼은 `읽기`, `저장`, `공유`처럼 결과가 보이는 동사. 같은 목적을 제목과 보조 설명에서 반복하지 않는다. 단위·대소문자·한글 띄어쓰기·아랍어 RTL은 서비스 언어 규칙과 콘텐츠 길이로 결정한다.

## I. 해도 되는 것 / 안 되는 것

1. 세리프 제목과 산세리프 UI를 조합할 수 있다(E1/E2). 본문 전체를 장식 세리프로 채워 판독성을 희생하지 않는다.
2. 단·룰·크레딧으로 위계를 만들 수 있다(E1/E3). 기사마다 동일한 카드와 그림자를 씌우지 않는다.
3. 제목 위에 사진을 배치할 수 있다(E1). 사진 위의 글자는 실제 사진별 대비를 측정한다.
4. 브랜드색으로 행동을 강조할 수 있다(E3). E3의 후원 화면 노란 버튼을 모든 편집 UI의 표준값으로 복제하지 않는다.

## J. 접근성 덮어쓰기

모바일 조작 영역 48×48 이상, 인접 8 이상, 본문·조작 글자 14 이상, 일반 텍스트 4.5:1·의미 있는 비문자 3:1을 검사한다. 메타 글자가 14 미만이면 키우고 기사 목록의 행 패딩과 줄수를 함께 다시 잰다. 폰트 150/200% 확대에서 다단을 1단으로 재배치하고 구획 룰·크레딧이 다른 기사에 붙지 않는지 확인한다. 변경은 `원안 값 → 접근성 값 → 이유 → 실제 캡처`로 남긴다.

## K. 미확인 목록

- E1~E3의 계산된 글꼴 이름/라이선스, 글자 단계, 간격 히스토그램, 색 픽셀, 룰 두께, R, 호버/누름 모션 전부 미측정.
- E2의 본문 그리드와 E3의 기사 화면은 첫 캡처에서 충분히 보이지 않음. 추후 해당 기사 상세를 따로 조사.
- 다크 모드는 세 서비스의 짝 화면을 확보하지 않았으므로 C의 다크값은 제안이다.

### K.2. guess 교체 기록

[기본 레퍼런스](../../samples/style-guess-books.html?style=editorial-print)의 C.1 토큰·E.4 부품·G.1 모션은 `편집 그리드·서체 대비·종이의 읽기 순서`을 구현한 `guess`이다. A는 스타일 신원, B는 실제 출처만 기록하고 추론으로 출처를 꾸며내지 않는다. D/F/H/I/J는 이 기본 레퍼런스를 기기·과업·문구·접근성에 맞게 재배치·확장하는 계약이다. L의 내부 렌더 PASS는 원본 일치 판정이 아니다. 새 원본에서 같은 부품과 상태를 발견하면 원본 화면의 값·프레임을 실측 → 현재 guess와 차이 기록 → 코드와 책 수정 → 다시 렌더 검수 → 해당 항목의 `guess` 태그 제거 순으로 갱신한다.
