현재 샘플의 차이: 현재 샘플은 제목을 크게 하고 한 덩어리를 움직일 뿐이다. 글자 단위 변형·사용자 입력·정지 상태의 읽기 위계를 보여줘야 한다.

이 계열의 알려진 시각 원리 `서체와 문구가 화면의 주 시각 요소이며 움직임이 정보의 순서를 만든다`에서 `글자 단위 순차 등장·정착, 마지막 상태는 정지`을 추론했다. 원본 동영상이 없어도 시연을 구현한다. 원본 움직임이라고 주장하지 않으며 나중에 실제 영상이 확인되면 궤적·축·중간 프레임·정착을 비교하고 `guess`를 제거하거나 수정한다.

## H. 문구

제목은 목적·화면 역할을 짧게 쓴다. 키네틱 타이포의 장식 문구가 기능 이름을 대신하지 않는다. 한글·영문 긴 문구와 RTL에서 줄바꿈·정렬을 확인한다.

## I. 허용·금지

| 허용 | 금지 |
|---|---|
| 서체와 문구가 화면의 주 시각 요소이며 움직임이 정보의 순서를 만든다을 과업에 필요한 영역에 적용 | 외형 때문에 필수 정보·조작을 가리기 |
| 화면 의미를 글자 크기·축·속도·순서로 전달한다. 모든 글자를 반복 이동시키지 않는다. | 가까운 스타일 `editorial-print; maximalism`의 효과를 그대로 복사 |

## J. 접근성

앱 조작 영역 48 이상과 모바일 조작 글자 14 이상을 시작 하한으로 확인 C에서 사용자에게 실제 기기 크기로 보여준다. 웹·문서는 매체별 하한을 별도로 확인한다. 색 대비, 150/200% 글자 확대, 키보드 순서, 모션 감소, 터치·드래그 대체를 검수한다.

## K. 미확인과 guess 교체

원본 URL·실제 부품 치수·원본 모션은 미확인이다. 현재 C/E/G의 값은 `guess`로 **구현하여 사용 가능한 기본 레퍼런스**다. 근거가 생기면 원본 상태를 실측하고 현재 결과와 비교해 값·샘플을 고친 뒤 해당 `guess`만 제거한다.

### K.2. guess 교체 기록

[기본 레퍼런스](../../samples/style-guess-books.html?style=kinetic-typography)의 C.1 토큰·E.4 부품·G.1 모션은 `서체와 문구가 화면의 주 시각 요소이며 움직임이 정보의 순서를 만든다`을 구현한 `guess`이다. A는 스타일 신원, B는 실제 출처만 기록하고 추론으로 출처를 꾸며내지 않는다. D/F/H/I/J는 이 기본 레퍼런스를 기기·과업·문구·접근성에 맞게 재배치·확장하는 계약이다. L의 내부 렌더 PASS는 원본 일치 판정이 아니다. 새 원본에서 같은 부품과 상태를 발견하면 원본 화면의 값·프레임을 실측 → 현재 guess와 차이 기록 → 코드와 책 수정 → 다시 렌더 검수 → 해당 항목의 `guess` 태그 제거 순으로 갱신한다.
