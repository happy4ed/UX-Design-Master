# Y2K / Chrome — 자유 스타일 가이드

## A. 신원

| 이름 | 분류 | 계열·기원 | 대상 버전 | 가이드 버전 | 확인일 |
|---|---|---|---|---|---|
| Y2K / Chrome | 자유 | 1990년대 말~2000년대 초 기술 낙관의 금속·액체·창 UI, 현대 재해석 포함 | 단일 UI 표준 없음 | 0.3.0-draft | 2026-11-05 |

**범위:** Y2K는 문화적으로 넓다. 크롬 금속, 유리 버블, 픽셀 창, 홀로그램을 같은 뜻으로 합치지 않는다. 이 가이드는 **크롬 재질**을 주도 축으로 하고 다른 하위 계열은 별도 변형으로 기록한다.

## D. 기기 모드·레이아웃

폰에서는 금속/홀로그램을 제목 또는 한 개의 주요 조작에 제한하고 읽기 열을 좁고 명료하게 유지한다. 폴드/태블릿에서는 재질을 넓게 보여줘도 복수 열의 정보 계위·탭 순서는 고정한다. 가로 모드에서 크롬 이미지가 본문을 덮지 않게 한다. 화면 여백·칸 구성·앱바 높이·시트 폭·안전 영역의 실측값은 `미확인`.

## E. 컴포넌트 명세

컴포넌트마다 `역할/금지 → 해부 → 크기 단계·패딩·글자·아이콘·R → 기본·누름·선택·비활성·포커스·끌기 → 라이트·다크 → hit area·간격 → 모션 → 근거·바꾼 것·미확인`을 기록한다. 다음 제안은 실서비스 3곳의 평균이 아니다.

| 부품·변형 | 스타일 출발점 | 근거 등급·출처 | 미확인 |
|---|---|---|---|
| 앱바(작은·큰 제목·부제), 뒤로 | 크롬 제목 장식과 기능 네비게이션을 층 분리 | 제안 Y4 | 치수·상태 |

## E.1. 글꼴·아이콘·슬라이더 결정

이 표는 컴포넌트별 구분이 누락되지 않도록 한 적용 계약이다. `제안`은 시연용 방향이며 원본 재현값이 아니다. 폰/폴드와 라이트/다크에서 각 부품의 기본·누름·포커스·끌기 상태를 따로 확인한다.

| 부품 | 형태·사용 규칙 | 근거 등급 | 상세 근거 |
|---|---|---|---|
| 글꼴 | 넓은 자간의 미래형 제목, 본문은 중립 서체 | 제안 | y2k-chrome.md C/E |
| 아이콘 | 반짝임 장식과 별개인 두꺼운 채움 기호 | 제안 | y2k-chrome.md C/E |
| 재생 위치 | 금속 광택 캡슐과 렌즈형 손잡이 | 제안 | y2k-chrome.md C/E |
| 음량 | 광택 트랙에서도 현재 값 경계를 유지 | 제안 | y2k-chrome.md C/E |

시연 SVG·CSS의 실제 속성은 [기준 화면](../../samples/style-book-reference-screen.html)에서 확인한다. 근거 없는 시연값은 이 가이드의 원본값으로 승격하지 않는다.

## F. 패턴

하위 화면+스위치, 목록/상세, 설정 묶음, 필터 고르기, 확인, 빈/로딩/오류, 여러 개 선택과 최대치는 기능명세로 정한다. Y2K는 역할·데이터를 대신하는 패턴이 아니다. 크롬 시각 표면과 실제 조작 표면을 나눠 그린다.

## G. 인터랙션

누름에 반사 하이라이트가 움직이는 표현은 **제안**, 화면 전환·시트·대화상자·끌기·햅틱은 `미확인`. 실물 같은 반사 방향이 누름 중 모순되지 않아야 하고, 움직이는 광택이 글자·수치 판독을 해치면 중지한다. 자동 반복은 모션 감소에서 정지한다.

## H. 문구 관례

레트로 장식형 타이포는 헤드라인에 한정하고 실제 기능명은 간결한 현대어로 쓴다. 픽셀 글꼴 때문에 작은 한글/다국어 글자가 깨지면 본문 폰트와 분리한다. 단위·상태 설명은 데이터 그대로. 공식 문체 규칙은 없음.

## I. 해도 되는 것 / 안 되는 것

1. 금속은 밝고 어두운 **반사 면의 관계**로 만든다. 아무 회색 그라데이션을 크롬이라고 부르지 않는다.
2. 주 조작 한두 곳에 광택을 집중한다. 모든 카드·시트·입력에 같은 반사와 블룸을 덮지 않는다.
3. Y2K의 크롬/픽셀/홀로그램/버블 하위 계열을 구분하고 화면마다 주도 재질을 한 가지로 정한다.

## J. 접근성 덮어쓰기

조작 영역 최소 `48×48`, 모바일 조작 글자 최소 `14`, 작은 글자 대비 `4.5:1`은 프로젝트 계약이다. Y1~Y3의 원값이 없어 현재 차이는 `미확인`; 실제 화면을 잰 뒤 바꾼 값 표를 작성한다. 150/200% 확대, 폰/폴드·라이트/다크에서 광택이 글자 경계를 지우지 않는지 확인한다.

## K. 미확인 목록

독립 실제 제품 사이트 3곳, Y1~Y3 픽셀 측정, 반사·그림자·블룸의 실제 값, 라이트/다크 대응, 폰/폴드 레이아웃, 부품별 상태/모션, 이미지 해시. 스타일 시연 3곳은 실제 제품의 공통 설계 근거를 대신하지 않는다.

### K.2. guess 교체 기록

[기본 레퍼런스](../../samples/style-guess-books.html?style=y2k-chrome)의 C.1 토큰·E.4 부품·G.1 모션은 `볼록한 크롬 반사와 금속의 깊이`을 구현한 `guess`이다. A는 스타일 신원, B는 실제 출처만 기록하고 추론으로 출처를 꾸며내지 않는다.
