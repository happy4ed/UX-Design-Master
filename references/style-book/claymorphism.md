## E.1. 글꼴·아이콘·슬라이더 결정

이 표는 컴포넌트별 구분이 누락되지 않도록 한 적용 계약이다. `제안`은 시연용 방향이며 원본 재현값이 아니다. 폰/폴드와 라이트/다크에서 각 부품의 기본·누름·포커스·끌기 상태를 따로 확인한다.

| 부품 | 형태·사용 규칙 | 근거 등급 | 상세 근거 |
|---|---|---|---|
| 글꼴 | 둥근 산세리프와 짧은 라벨 | 제안 | claymorphism.md C/E |
| 아이콘 | 두꺼운 둥근 기호 | 제안 | claymorphism.md C/E |

### E.2. 컴포넌트별 형태·상태·모션 변환

색 토큰만 바꿔 스타일을 적용했다고 판정하지 않는다. 아래는 [시연용 변환표](component-expression.json)의 기능형 **설계 가설**이다. 원본 사례 B절에서 확인된 성격과 E절의 부품 제안을 분리한다. 실제 원본 부품의 형상·누름·선택·모션을 확인하기 전에는 원본 일치로 쓰지 않는다. 같은 콘텐츠로 [13개 역할 보드](../../samples/style-book-component-board.html)에서 확인한다.

**원본 관찰 범위:** B절 C1–C3 — 점토 브랜드 아트와 C3 목업 직접 확인; 목업의 조작 부품은 비교적 평면적. **원본에서 아직 측정하지 못한 것:** 부푼 조작 부품을 원본 공통 규칙으로 일반화할 근거. 내부 [컴포넌트 계산 스타일·렌더 측정](../../samples/style-book-component-expression-audit.json)은 원본 실측이 아니다.

## G. 인터랙션

점토 느낌의 변형은 실제 행동을 설명할 때만 사용한다. 누름은 손의 접촉 지점에서 작게 눌리고 원상 복귀한다. 화면 전환은 정보 위치를 유지한다. 시트/대화상자는 입체 장식 때문에 늦어지지 않게 한다. 끌기 컨트롤은 상태/값이 먼저 따라와야 한다. 진동은 물리 은유와 맞는 경우에 한해. 공통 시간·이징은 실측되지 않아 `미확인`(C2의 물성 원리에서 파생).

### G.1. 기본 모션북 — guess 구현

이 계열의 알려진 시각 원리 `부푼 덩어리와 부드러운 위쪽 하이라이트`에서 `탄성 압축과 느린 복원`을 추론했다. 원본 동영상이 없어도 시연을 구현한다. 원본 움직임이라고 주장하지 않으며 나중에 실제 영상이 확인되면 궤적·축·중간 프레임·정착을 비교하고 `guess`를 제거하거나 수정한다.

## H. 문구 관례

제목은 기능·목적을 짧게 표현한다. 어린이 같은 말투를 스타일 때문에 강제하지 않는다. 장식 도형 위에 긴 글자를 넣지 않고 텍스트 박스를 먼저 정한다(제안).

## I. 해도 되는 것 / 안 되는 것

1. 3D 점토 아트를 초점 장면에 사용한다 / 카드·행·버튼을 전부 같은 부푼 모양으로 만들지 않는다(C1–C3).
2. 빛·그림자·접촉 방향을 하나의 장면처럼 맞춘다 / 안쪽·바깥 그림자를 무작위로 쌓지 않는다(C2).
3. 실제 조작은 텍스트·상태·포커스가 읽히게 한다 / 입체 느낌만으로 클릭 가능성을 전달하지 않는다(C3 제안).
4. 브랜드의 점토 일러스트를 새 제품의 부품 정본이라고 주장하지 않는다(C1,C2).

### K.2. guess 교체 기록

[기본 레퍼런스](../../samples/style-guess-books.html?style=claymorphism)의 C.1 토큰·E.4 부품·G.1 모션은 `부푼 덩어리와 부드러운 위쪽 하이라이트`을 구현한 `guess`이다. A는 스타일 신원, B는 실제 출처만 기록하고 추론으로 출처를 꾸며내지 않는다. D/F/H/I/J는 이 기본 레퍼런스를 기기·과업·문구·접근성에 맞게 재배치·확장하는 계약이다. L의 내부 렌더 PASS는 원본 일치 판정이 아니다. 새 원본에서 같은 부품과 상태를 발견하면 원본 화면의 값·프레임을 실측 → 현재 guess와 차이 기록 → 코드와 책 수정 → 다시 렌더 검수 → 해당 항목의 `guess` 태그 제거 순으로 갱신한다.
