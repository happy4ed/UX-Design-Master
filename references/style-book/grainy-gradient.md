## H. 문구

제목은 목적·화면 역할을 짧게 쓴다. 그레이니 그라데이션의 장식 문구가 기능 이름을 대신하지 않는다. 한글·영문 긴 문구와 RTL에서 줄바꿈·정렬을 확인한다.

| 허용 | 금지 |

## J. 접근성

앱 조작 영역 48 이상과 모바일 조작 글자 14 이상을 시작 하한으로 확인 C에서 사용자에게 실제 기기 크기로 보여준다. 웹·문서는 매체별 하한을 별도로 확인한다. 색 대비, 150/200% 글자 확대, 키보드 순서, 모션 감소, 터치·드래그 대체를 검수한다.

### K.2. guess 교체 기록

[기본 레퍼런스](../../samples/style-guess-books.html?style=grainy-gradient)의 C.1 토큰·E.4 부품·G.1 모션은 `부드럽게 번진 색층 위 균일한 미세 입자, 글자 영역은 선명`을 구현한 `guess`이다. A는 스타일 신원, B는 실제 출처만 기록하고 추론으로 출처를 꾸며내지 않는다. D/F/H/I/J는 이 기본 레퍼런스를 기기·과업·문구·접근성에 맞게 재배치·확장하는 계약이다. L의 내부 렌더 PASS는 원본 일치 판정이 아니다. 새 원본에서 같은 부품과 상태를 발견하면 원본 화면의 값·프레임을 실측 → 현재 guess와 차이 기록 → 코드와 책 수정 → 다시 렌더 검수 → 해당 항목의 `guess` 태그 제거 순으로 갱신한다.
