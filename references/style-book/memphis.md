## D. 기기 모드·레이아웃

폰은 패턴이 본문을 가리지 않도록 장식층을 콘텐츠 뒤 또는 구획 가장자리에 둔다. 폴드/태블릿에서는 추가 공간에 패턴을 넓힐 수 있으나 **타이포·조작의 기준선은 유지**한다. 가로 모드에서는 그림보다 먼저 탐색·본문 순서를 보존한다. 화면 여백·칸 구성·앱바 높이·대화상자 폭·안전 영역의 실측값은 `미확인`.

## E. 컴포넌트 명세

각 컴포넌트는 `역할/금지 → 해부 → 크기 단계·패딩·글자·아이콘·R → 기본·누름·선택·비활성·포커스·끌기 → 라이트·다크 → hit area·인접 간격 → 모션 → 근거·바꾼 것·미확인`을 실제 서비스 화면에서 기록한다. 아래는 M4 기반 **제안**, 운영 사이트 3개 실측의 공통값이 아니다.

## E.1. 글꼴·아이콘·슬라이더 결정

이 표는 컴포넌트별 구분이 누락되지 않도록 한 적용 계약이다. `제안`은 시연용 방향이며 원본 재현값이 아니다. 폰/폴드와 라이트/다크에서 각 부품의 기본·누름·포커스·끌기 상태를 따로 확인한다.

| 부품 | 형태·사용 규칙 | 근거 등급 | 상세 근거 |
|---|---|---|---|
| 글꼴 | 대비가 큰 그래픽 제목과 읽기 쉬운 본문 | 제안 | memphis.md C/E |
| 아이콘 | 장식은 바깥, 기능 기호는 단순한 채움 | 제안 | memphis.md C/E |
| 재생 위치 | 분절된 색 트랙과 원형 썸 | 제안 | memphis.md C/E |
| 음량 | 패턴과 조작 영역을 분리한 밝은 막대 | 제안 | memphis.md C/E |

시연 SVG·CSS의 실제 속성은 [기준 화면](../../samples/style-book-reference-screen.html)에서 확인한다. 근거 없는 시연값은 이 가이드의 원본값으로 승격하지 않는다.

### E.2. 컴포넌트별 형태·상태·모션 변환

색 토큰만 바꿔 스타일을 적용했다고 판정하지 않는다. 아래는 [시연용 변환표](component-expression.json)의 기능형 **설계 가설**이다. 원본 사례 B절에서 확인된 성격과 E절의 부품 제안을 분리한다. 실제 원본 부품의 형상·누름·선택·모션을 확인하기 전에는 원본 일치로 쓰지 않는다. 같은 콘텐츠로 [13개 역할 보드](../../samples/style-book-component-board.html)에서 확인한다.

**원본 관찰 범위:** B절 M1–M3 — 원형 가구·그래픽과 운영 사이트. **원본에서 아직 측정하지 못한 것:** 조작 부품의 실제 상태·모션 수치. 내부 [컴포넌트 계산 스타일·렌더 측정](../../samples/style-book-component-expression-audit.json)은 원본 실측이 아니다.

### E.4. 기본 컴포넌트북 — guess 구현

원본에서 모든 부품을 보지 못해도 아래 규칙으로 **실제 조작 가능한 기본 레퍼런스**를 만든다. `guess`는 미구현이 아니라 현재 사용 가능한 추론안이다. 앱·웹은 같은 역할을 유지하고 문서에서는 조작을 상태·다음 행동으로 번역한다. [작동 샘플과 모션북](../../samples/style-guess-books.html?style=memphis)에서 확인한다.

| 부품 | 데이터·상태 경계 | 형태/표현 규칙 | 등급·근거·교체 조건 |

## F. 패턴

하위 화면+스위치, 목록/상세, 설정 묶음, 필터 고르기, 확인, 빈/로딩/오류, 여러 개 선택과 최대치는 과업 명세로 먼저 구조화한다. 패턴·기하 도형은 **모든 컨테이너에 넣는 기본 배경이 아니다.** 화면마다 장식 밀도와 기능 밀도를 분리해 검증한다.

## G. 인터랙션

누름은 선택된 색면/도형의 위치·크기로 피드백하는 후보. 전환·시트·대화상자·끌기·햅틱의 공통 Memphis 모션 규격은 없음. 패턴 자체가 계속 움직여 중요한 정보를 가리지 않도록 한다. 값과 동작은 `미확인`.

## H. 문구 관례

시각적으로 장난스러워도 버튼 문구는 기능을 말한다. 대문자·기울임 장식은 헤드라인에 제한하고 긴 한글·다국어 본문은 일반 글꼴·라인 간격으로 읽히게 한다(제안). 공식 문체·단위 규칙은 없음.

## I. 해도 되는 것 / 안 되는 것

1. 원형·지그재그·색면의 조합을 **원형 작품**으로 확인한다. 아무 도형을 무작위로 뿌린 것을 Memphis라고 부르지 않는다.
2. 장식층과 정보층을 분리한다. 패턴 위에 장문 텍스트/작은 조작을 직접 올리지 않는다.
3. 원형 디자인과 `Corporate Memphis` 일러스트를 혼동하지 않는다.

## J. 접근성 덮어쓰기

조작 영역 최소 `48×48`, 모바일 조작 글자 최소 `14`, 작은 글자 대비 `4.5:1`은 프로젝트 계약이다. M1의 실측 원값이 없어 차이 수치는 `미확인`; 화면별로 바꾼 색·글자·hit area를 기록한다. 150/200% 글자 확대, 패턴 위 텍스트, 폰/폴드·라이트/다크를 실제 렌더로 확인한다.

## K. 미확인 목록

독립 실서비스 3곳, M1 실측 토큰, 라이트/다크 실제 모드, 폰/폴드 화면, 컴포넌트별 상태와 인터랙션, 모션, 원본 캡처 해시. 원형 작품 3곳 관찰은 서비스 UI 3곳 검증을 대신하지 않는다.
