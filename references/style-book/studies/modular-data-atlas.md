# 모듈형 데이터 아틀라스 — 이미지 기반 스타일 실험

## A. 신원과 정의

| 항목 | 내용 |
|---|---|
| 표시 이름 | 모듈형 데이터 아틀라스 |
| ID | `modular-data-atlas` |
| 성격 | 작은 데이터 설명 단위를 반복하는 인포그래픽 편집 스타일. 앱·웹·문서에 번역 가능하나 이 사례의 원형은 인쇄형 포스터다. |
| 핵심 정의 | 하나의 질문과 한 종류의 차트를 한 모듈로 묶고, 여러 모듈을 얇은 선·공통 색상 의미·일정한 제목 계층으로 배열한다. |
| 필수 특징 | ① 밝은 종이 같은 바탕 ② 청록·주황·회색의 안정된 의미 분담 ③ 작은 제목+짧은 설명+그림+범례/수치의 반복 구조 ④ 차트 종류별 일관된 축·마크·캡션 ⑤ 카드 그림자 대신 선과 여백으로 구획 |
| 가변 요소 | 색의 정확한 RGB, 글꼴, 열 수, 모듈 크기, 데이터 분야. 단, 의미 색과 읽기 순서는 한 산출물 안에서 일관되어야 한다. |
| 이 스타일이 아닌 경우 | 차트만 여럿 모은 화면, 의미 없이 청록/주황을 칠한 화면, 모든 차트를 카드 그림자로 감싼 대시보드, 값과 단위가 없는 장식용 도표. |
| 가까운 계열 | Swiss Grid의 정렬 원칙과 Flat 2의 평면 색 사용. 이 사례는 **서로 다른 차트를 공통 모듈 문법으로 편집**하는 점이 구별된다. |

원본은 단일 이미지다. 따라서 이 문서의 **관찰**은 이미지의 출력 픽셀과 보이는 형태에 한정한다. 인터랙션·원본 CSS·모션·반응형 규칙은 확인되지 않았으며 시연에서 보충한 값은 모두 `guess`다. 이미지의 작은 로렘 입숨 문장은 읽을 수 없어 콘텐츠 규칙의 증거로 사용하지 않는다.

## E. 컴포넌트북

### E.1 앱·웹 공통 컴포넌트 계약 — 이미지 기반 추론

원본은 차트 포스터이므로 아래 앱·웹 부품은 모두 `guess`다. 종이색 바탕, 얇은 회색 선, 청록·주황 마크와 좌측 정렬을 공유한다. 평면 색만 적용하고 조작별 상태를 생략해서는 안 된다. [실제 컴포넌트와 모션 시안](../../../samples/modular-data-atlas-components.html)에서 조작할 수 있다.

| 부품 | 역할과 형태 | 상태·입력·경계 |
|---|---|---|
| 앱바·내비 | 제목과 현재 위치, 그림자 없는 하단 구분선 | 메뉴 키보드 이동, 좁은 폭에서는 줄바꿈 |
| 탭 | 구획 전환, 선택된 항목에 청록 기준선 | 선택·포커스, 키보드 화살표 |
| 버튼 | 주 행동은 청록 면, 보조 행동은 선과 글자 | 기본·호버·포커스·비활성; 긴 글자 줄바꿈 |
| 검색·입력 | 평평한 밝은 면과 얇은 선, 라벨 상시 표시 | 값 입력·포커스·오류 메시지, 긴 값 스크롤 |
| 체크·라디오·스위치 | 선택을 기호와 색으로 표현 | 선택·해제·키보드·포커스, 색만으로 구분 금지 |
| 슬라이더 | 선 위 원형 핸들과 값 | 화살표 키와 포인터, 최소·최대 표시 |
| 목록·구획 | 테두리 카드 대신 수평선과 좌측 기준선 | 긴 행 자동 확장, 선택과 상태를 글자로 표시 |
| 배지·진행 | 숫자/상태의 의미 표시 | 단위와 텍스트 병기, 진행값 변경 시 갱신 |
| 대화상자·시트 | 밝은 면과 제목·본문·명확한 선택 | 열기·닫기·Escape·포커스 복귀; 모바일에서는 화면 안에 맞춤 |
| 알림·빈/오류 | 메시지와 복구 행동 | 색 외 텍스트 사용, 긴 설명 줄바꿈 |

## F. 데이터·내용 패턴

시연 데이터는 **가상 도시 이동 조사**로 고정한다. 각 차트는 같은 `분모=100명`을 사용하고 교통수단별 합계가 100이 되도록 한다. 화면 전환 시 제목·원형·막대·픽셀·타임라인의 집단명이 함께 바뀐다. 원본의 숫자·문구를 재사용하지 않는다. 긴 명칭과 작은 수치에서는 라벨이 차트 밖으로 밀리지 않도록 아래에 직접 표기한다.

## G. 모션북

정지 이미지에서 원본 움직임은 **0건 확인**. 아래는 정보 판독을 돕기 위한 `guess`이며 원본 재현이 아니다.

| 동작 | 트리거 | 시작→끝 | 정적 대안 | 확인 |
|---|---|---|---|---|
| 집단 변경 | 필터 클릭/키보드 | 값·라벨 즉시 갱신, 막대 길이·링만 짧게 이동 | 즉시 최종값 표시 | 데모, guess |
| 상세 강조 | 그래프 항목 선택 | 선택 항목에 얇은 테두리와 인접 설명 노출 | 동일 테두리와 설명 | 데모, guess |
| 값 집중 | 마크 호버·포커스 | 같은 계열의 마크만 조금 진해짐 | 직접 라벨 유지 | 데모, guess |

반복 펄스나 장식용 무한 루프는 두지 않는다. `prefers-reduced-motion`에서는 전환 없이 최종 상태를 표시한다.

## H. 색 의미·차트 선택

원형은 단일 비율, 막대는 항목 간 비교, 픽셀 행은 이산 분포, 타임라인은 시점과 순서에만 사용한다. 범례의 색 하나를 여러 의미로 재사용하지 않는다. 원형 차트로 작은 범주 차이를 비교하지 않고 막대를 쓴다.

## I. 조합·정렬 규칙

모듈마다 `제목 → 설명 → 차트 → 범례/수치` 순서를 유지한다. 구분선과 차트 축을 열 격자에 맞춘다. 원형 마크는 박스 정렬뿐 아니라 보이는 링 중심을 맞춘다. 범례 기호와 글자의 간격은 같은 행에서 반복값을 사용한다. 데이터가 부족한 모듈은 빈 그림을 늘이지 말고 근거와 빈 상태를 보여준다.

## J. 접근성·다국어

웹 샘플의 본문은 최소 14px을 설계값으로 사용하고 실제 확대 상태에서 재검수한다. 조작 표적은 최소 44×44 CSS px. 그래프는 숫자·단위·텍스트 설명을 제공하며 키보드로 필터와 상세를 조작할 수 있다. 고정 폭 텍스트 박스를 쓰지 않고 한글/영문 긴 라벨을 줄바꿈한다. RTL은 DOM 순서를 보존한 채 방향·축 라벨을 별도로 확인해야 한다.
