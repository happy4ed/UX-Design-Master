# Pinterest 네오 부르탈리즘 핀 스타일 연구

## 범위와 근거

- 원본: https://kr.pinterest.com/pin/978195981582851360/
- 확인일: 2026-11-05. 원본 이미지 1080×1920 JPEG. Pinterest `og:image`에서 연결된 원본을 실제 열어 확인했다. 외부 이미지는 배포 스킬에 보관하지 않는다.
- 이미지 SHA-256: `493f0bee1257d42de5c8913a812acd3f7f9780535f9f4d8eb17d83392b06d9c1`. 원본 파일은 `/tmp`에만 둔다.
- 성격: 작동하는 제품 화면이 아닌 **디자인 시스템 포스터**. 눌림·호버·스크롤·모션·실제 hit area는 원본에서 관찰할 수 없다.
- 가까운 기본 스타일: `references/style-book/neo-brutalism.md`. 이 표본은 별도 보편 스타일이 아니라 `neo-brutalism--teal-magenta-yellow` 변형 후보이다. 한 장의 핀을 네오 부르탈리즘 전체의 공통값으로 승격하지 않는다.

원본은 JPEG이며 색 가장자리와 글자 주변에 압축 오차가 있다. 아래 RGB는 평평한 내부 픽셀의 5×5 채널별 중앙값으로, 원본의 CSS 토큰 자체는 아니다. `scripts/measure_screenshot.py`와 같은 방식으로 확인했다.

## 컴포넌트 변환 규칙

| 역할 | 원본에서 보이는 형상 | 작동 샘플 변환 | 원본에서 미확인 |
|---|---|---|---|
| 주/보조 버튼 | 청록 채움, 흰색·베이지 윤곽, 검정 선, 오프셋 그림자 | 주 행동만 청록+그림자, 보조는 베이지/흰 면 | 누름·호버·비활성 전환 |
| 입력 | 네모 검정 외곽, 오류는 붉은 외곽 | 기본/포커스/오류를 직접 구현 | 포커스 두께·키보드 |
| 탭·단계 | 직선 레일, 색으로 현재 단계 표기 | 탭은 콘텐츠 전환, 단계는 진행 표시로 역할 분리 | 실제 스크린리더 구조 |
| 체크·스위치 | 검정 기하, 켜짐은 노랑 | 네이티브 입력 위에 스타일, 키보드 조작 유지 | 토글 애니메이션 |
| 카드·리스트·표 | 검정 경계, 일부만 하드 그림자 | 리스트는 선 중심, 강조 카드만 그림자 | 행 hover·정렬 동작 |
| 알림·모달 | 색면 + 검정 선/그림자 | 실제 닫기, ESC, 포커스 반환 | 원본 모션 |

모션은 원본 정지 이미지에 없으므로 **설계 가설**이다. 버튼 누름의 그림자와 위치를 함께 이동시키고, 시트/모달은 한 번의 짧은 등장으로 구현한다. 원본 일치 판정은 하지 않는다.

## 가안 대조와 검증

- 샘플: `samples/pinterest-neo-brutalism.html`의 `작동 샘플`과 `스타일 명세` 전환.
- 동일한 점: 베이지 바탕, 검정 선, 청록·마젠타·노랑, 헤드라인 대비, 절제된 하드 그림자, 구획선, 각진 아이콘·조작.
- 의도적으로 바꾼 점: 세로형 포스터의 밀집 그리드를 실제 앱의 읽기 순서와 반응형 열로 바꿈. 이미지의 작은 글자와 44px 조작 영역을 키움. 실제 상태와 포커스/키보드·모션을 추가함.
- 확인 불가: 원본 웹/앱 CSS, 정확한 폰트명, hover/pressed/drag·모션, 다크 모드, 실제 hit area. 이 항목들은 샘플의 기능형 설계 가설이다.
- 이 한 장만으로 보편 디자인 시스템을 확정하지 않는다. 사용자 선택 후 사용자 스타일북에 변형으로 등록한다.
- 브라우저 검증: 1440×900, 390×844에서 가이드/샘플을 렌더했다. 좁은 화면의 가로 넘침 0, 표시 글자 최소 14 CSS px, 조작 영역의 짧은 축 최소 48 CSS px. 체크를 누르면 완료율 25→50%, 작업 추가 뒤 목록에 새 항목 등장, 필터 결과 갱신, 모달 열림을 확인했다. 페이지 오류 0. 이 수치는 샘플 자체의 검증 결과이며 Pinterest 원본 일치 판정은 아니다.
