# 고유 모션별 제작 명세

직접 제작한 모션의 정지 장면을 재사용할 때는 [모션 스틸 샘플](../samples/motion-stills/index.html)과 [생성 기록](../samples/motion-stills/manifest.json)을 참고한다. 정지 장면만으로 움직임의 경로·순서·주기를 검증하지 않는다.

[343종 제작 계약](../knowledge/motion-authoring-recipes.json)은 [모션·컴포넌트 KG](motion-component-graph.md)와 같은 대표 ID를 사용한다. [브라우저 명세 탐색 화면](../samples/motion-authoring-catalog.html)에서 각 항목을 볼 수 있다. 각 항목에는 움직이는 대상 후보, 시작·핵심 변화·끝, 기존 효과로 잘못 대체하지 말아야 할 동작, 원본 제작 단서, 매체별 구현 경로, 정적·움직임 감소 대안, 검증 항목이 있다. 이 계약은 **제작 입력**이다. JSON이 존재한다는 이유로 원본 일치나 시연 완성을 PASS로 표시하지 않는다.

## 모션을 선택하고 만드는 순서

1. 화면의 컴포넌트 ID, 사용자 사건, 이전·이후 정보 상태를 정한다. KG의 `candidate_for`에서 활용 유형과 움직임 규모로 후보를 좁힌다. 후보가 화면의 역할을 설명하지 못하면 사용하지 않는다.
2. 해당 ID의 `motionPrinciple.action`과 `doNotSubstitute`를 먼저 읽는다. `sourceSnapshot`에 해당하는 `capturedSourceBehavior`와 `capturedProductionPrompt`는 과거 원본 문구다. `userCorrectionApplied=true`이면 이후 사용자 수정이 제작 정의의 우선 근거다. 원본 텍스트의 수치와 제품 설계값을 섞지 않는다.
3. 움직이는 실제 대상, 첫 장면, 결정적 중간 장면, 끝 장면을 해당 제품 콘텐츠로 그린다. `decisiveMiddle`은 자동으로 확정된 프레임이 아니다. 원본과 내부 시연을 직접 재생해 핵심 변화가 보이는 시점을 선택한다.
4. 대상 크기·위치·거리/각도·시간·이징·트리거·반복·중단·역전·모션 감소를 프로젝트 값으로 채운다. 공간 범위 태그 `small/medium/large/screen`은 검색용이고 실제 이동량이나 강도 토큰이 아니다.
5. 적합한 매체 경로로 구현한 뒤 시작·중간·끝, 빠른 재입력, 뒤로 가기, 포커스·스크롤, 정적 상태를 실제 출력 크기에서 검증한다. 브라우저 데모의 PASS를 네이티브 앱·PPT·문서의 PASS로 이월하지 않는다.

## 매체 변환 계약

| 매체 | 제작 경로 | 빠지면 실패하는 것 |
| --- | --- | --- |
| 웹 | 상태 모델을 DOM·ARIA와 연결하고 CSS/WAAPI/SVG/Canvas/WebGL 중 해당 동작을 표현하는 경로 사용 | 빈 프레임, 중단 시 상태 튐, 동작 없는 조작, 모션 감소에서 정보 소실 |
| 네이티브 앱 | 동일한 상태 기계를 플랫폼 애니메이션·벡터·캔버스/3D로 변환; 시스템 모션 감소와 뒤로 가기를 연결 | 실제 기기에서 터치·스크롤·포커스·재입력 불일치 |
| PPT/발표 | 핵심 경로를 편집 가능한 도형 단계로 재현할 수 있으면 사용; 복잡한 마스크·합성·3D·물성은 렌더된 로컬 영상으로 삽입하고 마지막 상태를 정지 슬라이드로 보존 | 슬라이드 넘김과 모션 트리거 불일치, 영상 미재생 시 정보 누락, 폰트·좌표 틀어짐 |
| 정적 문서/PDF·인쇄 | 최종 상태와 필요하면 시작·결정적 중간·끝의 연속 도해로 의미를 보존 | 움직여야만 관계·값을 이해할 수 있는 상태 |
| 대화형 HTML 문서 | 웹 경로와 동일하게 구현하고 출력·인쇄 시 정적 대안을 제공 | 인쇄/PDF에서 글자·데이터·순서 소실 |

PPT 내장 애니메이션의 지원 범위, 앱 프레임워크 API, 브라우저 지원은 실제 도구·버전에서 확인한다. 명세에는 도구 선택을 강제하지 않는다. 에셋을 MP4/GIF/SVG 등으로 내보내야 하는 경우 프레임 크기·배경 투명도·재생 방식·마지막 정지 프레임·오디오 유무를 결과물별로 기록한다.

## 완료 기록

한 항목을 실제 제품에서 사용했다면 `motionId / componentId / 화면·슬라이드 ID / 사건 / 시작·중간·끝 캡처 / 실제 거리·각도·시간·이징 / 중단·역전 / 모션 감소·정적 대안 / 출력 매체·버전 / 원본 대조 / 사용자 결정`을 남긴다. 누락된 값은 `NOT_RUN` 또는 `미확정`으로 둔다. 343종의 제작 명세가 채워졌다는 것과 343종이 모든 매체에서 구현·검증됐다는 것은 별도 사실이다.
