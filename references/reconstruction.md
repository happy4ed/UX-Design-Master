# 재구현과 비교 검증

## 먼저 구분할 작업

| 모드 | 결과 | 기본 경로 |
| --- | --- | --- |
| 참고 분석 | 컴포넌트·규칙·문제·출처 | 관찰→계약·도면; 코드 재구현 없음 |
| 개선 | 기존 목적·브랜드를 보존한 수정 | 기준 화면 고정→문제·근거→수정→전후 비교 |
| 정밀 재현 | 주어진 화면/상태에 맞춘 로컬 구현 | 동일 조건의 실렌더 비교 |
| 독립 재구현 | 익숙한 기능·흐름의 별도 구현 | feature/flow 계약과 자체 시스템 |
| 소유 사이트 이전 | 기존 콘텐츠·URL·동작 보존 | 승인된 원본과 라우트·기능·시각 회귀 검사 |
| 런타임 미러 | 원본 정적 자산·런타임의 로컬 실행 | 명시적으로 요청·허용된 범위에 한정 |

미러가 원본처럼 보인다는 것은 유지 가능한 독립 구현이나 일반화된 규칙 추출의 증거가 아니다. 공개 URL 또는 참고 화면 제공만으로 원본 번들 재배포·서비스 게시·스택 교체를 승인받았다고 해석하지 않는다. 사용자가 요청한 분석·구현 범위 안에서 수행한다.

## 소스 유형별 분석

- **URL:** 필요한 화면·상태의 DOM·계산 스타일·폰트·자산·실렌더를 연결한다. 읽을 수 없는 CSS 규칙은 모르는 상태로 남긴다. 같은 측정 함수를 원본과 구현에 적용한다.
- **앱 스크린샷:** screen→states를 먼저 묶고 탐색 그래프는 관찰과 추정을 구별한다. 이미지 픽셀과 논리 viewport를 별도 기록한다. Expo 웹 캡처의 일치가 실제 iOS/Android 동작·타이포그래피 일치를 증명하지 않는다.
- **녹화·동적 페이지:** 트리거, 실제 입력, 전환 전·중·후, 역전·중단을 관찰한다. 필요하면 타임스탬프 프레임을 비교한다. 스크립트 scrollTo만으로 wheel·touch·smooth-scroll 동작을 검증하지 않는다.
- **Canvas/WebGL/Rive:** DOM만으로 내부 장면을 복구할 수 없다. 장면·타임라인·원본 모델이 없으면 시각 관찰·추정 범위를 명시한다. 정적 이미지로 대체한 것을 인터랙티브 장면 재현이라 하지 않는다.

## 구현 전의 실행 가능한 명세

페이지/영역마다 source ID, viewport·DPR·crop, 구조·bbox/제약, anatomy, 필수/선택 슬롯, 데이터 표시 계약, 자산 역할, 토큰 후보, 상태, 통과 조건을 만든다. 섹션 이름만 있는 ‘명세’로 구현을 시작하지 않는다. 이미지·아이콘·텍스트를 빠뜨려 생긴 차이를 CSS 미세 조정으로 해결하지 않는다.

컴포넌트 목록·실제 사용 맵·선행 공유 토큰을 먼저 만든다. 새 제품 설계는 본 스킬의 사용자 확인 A1/A2/A3/B/C를 따른다. 이미 승인된 화면의 재현은 원본 방향을 다시 선정하게 하지 않는다. 작업 분할이나 병렬 실행은 현재 환경 지침과 사용자 승인 범위에 따르며 외부 스킬의 고정 에이전트 수를 가져오지 않는다.

## 검증과 수정 루프

1. 같은 viewport·DPR·zoom·font·theme·locale·data·state·scroll/time에서 비교한다.
2. 원본이 반복 캡처마다 달라지면 자기 비교로 노이즈를 확인한다. 비교용 정지 상태와 실제 동작 검증은 별개로 보존한다. reference/candidate에 동일하게 적용한 mask·freeze를 기록한다.
3. 페이지 전체→영역별→핵심 컴포넌트 순으로 비교한다. 빈 배경이 전체 점수를 높여 작은 버튼 오류를 가리지 않게 한다.
4. 차이를 환경/데이터/자산/구조/anatomy/토큰/동작/측정 오류로 분류한다. 소유 컴포넌트나 공유 규칙에 연결한다.
5. 원인을 수정하고 영향받는 화면·상태와 Initial/Saturated를 다시 검사한다. 지표를 통과시키려고 원본·임계값·명세를 몰래 바꾸지 않는다.
6. 개선이 멈추거나 필요한 증거가 없으면 최선 버전과 남은 차이를 보존한다. 무한 수정 루프를 돌리지 않는다. 남은 기능·관찰 누락·폰트·플랫폼 차이를 구체적으로 보고한다.

평가는 **구조 일치 / 시각 일치 / 기능·흐름 일치 / 동작·시간 일치 / 콘텐츠·접근성 내구성**으로 분리한다. pixel diff·SSIM·엣지 맵은 진단 도구이며 전체 정렬·품질·사용성을 대표하는 단일 합격 점수가 아니다. 픽셀 이미지나 캡처를 통째로 화면 배경으로 깔아 유사도를 올리지 않는다. 자동화가 못 확인한 항목은 NOT_RUN으로 남긴다.

## 내부 판단 경계

정밀 재현은 같은 증거 조건에서 구조·시각·동작의 차이를 줄이는 작업이다. 독립 재구현은 역할·기능·흐름 계약을 충족하되 자체 디자인 시스템으로 구현할 수 있다. 런타임 미러는 그 자체로 재사용 가능한 설계 규칙을 제공하지 않는다. 이 구분과 위 검증 루프는 외부 스킬 실행 없이 적용한다. 과거 소스별 조사 기록은 운영 지침 밖의 연구 산출물로 보존한다.
