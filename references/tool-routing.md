# 내부 설계 원칙과 실행 도구 등록부

이 스킬은 앱·웹·문서의 의미 구조, 와이어프레임, 시각 시스템, 다이어그램·인포그래픽 표현 유형과 검수 기준을 **내부 원칙**으로 결정한다. 시각화 생성은 스킬 내부의 데이터 문법·템플릿·SVG 렌더러·모션 CSS로 실행한다. 외부 디자인 스킬·템플릿·렌더러·CDN을 설치·호출·연결하지 않는다. PPT·영상 제작/변환은 후속 출력 도구 영역이다.

## 실행 수단의 선택 순서

1. 결과물을 분석 보고서, 구조 명세, 와이어프레임, 편집 가능한 디자인, 실행 UI, 문서, 차트, 다이어그램, 인포그래픽 중 하나로 정의한다.
2. 기존 프로젝트의 스택·브랜드·편집 도구·지원 매체·출력 형식을 확인한다.
3. 내부 데이터·컴포넌트·정렬·다국어 계약을 먼저 정한다. 렌더러의 템플릿이나 미학이 구조를 결정하게 하지 않는다.
4. 내부 렌더러로 표현할 수 없는 의미 유형이면 원본 자료와 출력 요구를 먼저 정의하고 내부 문법·템플릿·검증을 확장한다. 일반 UI 구현이나 문서 편집 도구는 결과물 형식에 맞춰 선택한다.
5. 렌더된 결과와 원본 데이터를 대조한다. 실행 성공·자동 검사 통과만으로 디자인 검수를 완료하지 않는다.

## 필수 능력과 가능한 도구

| 작업 | 필요한 능력 | 구현 수단의 예 | 대체 가능성·판정 기준 |
| --- | --- | --- | --- |
| 원본·레퍼런스 분석 | 화면/문서 원본 열람, 출처·관찰 범위 기록 | 브라우저, 연결된 소스, 사용자가 제공한 캡처 | 원본을 볼 수 없으면 관찰 범위를 제한. 썸네일만으로 동작 추정 불가 |
| 구조·와이어프레임 | 역할·내용 구조표, 같은 콘텐츠의 3개 저충실도 대안 | HTML/CSS/SVG, 기존 디자인 편집기 | 같은 초기/포화 조건과 매체 변화를 보여줄 수 있으면 교체 가능 |
| 시각 시스템 | 색·서체·간격·정렬·자산 토큰, 실제 렌더 | 기존 제품 스택, HTML/CSS, 디자인 편집기 | 편집성·브랜드 자산·최종 납품 형식으로 판단 |
| 관계도·구조도·인포그래픽 | 노드·관계·척도·캡션을 직접 통제하는 벡터 표현 | [내부 시각화 엔진](../assets/visualization/renderer.mjs)과 [카탈로그](visualization-catalog.md) | 55개 유형의 샘플 SVG 생성 완료. 자동 레이아웃과 임의 복잡도는 지원 범위를 따로 확인 |
| 공간 조감·부품 분해 | 너비·깊이·높이를 가진 3D 좌표에서 보이는 면을 SVG로 투영 | [내부 3D 장면 렌더러](../assets/visualization/scene3d.mjs)와 `scripts/render_spatial_scene.mjs` | 상자형 공간·부품의 정사영, 자동 화면 맞춤, 깊이 순서. 자유형 메시·원근 카메라는 지원 범위 밖 |
| 구성 선택용 모션 | 순서·상태·값 변화의 저충실도 시연, 정지·모션 감소 | 내부 SVG CSS 모션과 독립 HTML 내보내기 | 실제 사용자 흐름과 정적 대체를 비교. 장식 효과만으로 관계를 주장하지 않음 |
| 규모가 큰 정량·상호작용 차트 | 축·척도·툴팁·반응형·데이터 갱신 | 의미 계약을 유지하며 내부 엔진 확장 | 현재 55개는 고정 문법·소량 데이터의 렌더러. 대규모 자료는 별도 성능 검증 필요 |
| 문서 렌더·검수 | 최종 판형/화면에서 페이지 넘김과 번호 대조 | 기존 문서 편집기·브라우저·PDF 렌더러 | 원본 편집성과 출력 충실도 둘 다 확인 |
| 시각·상호작용 검수 | 실제 렌더, 기하 측정, 키보드·접근성, 다국어·RTL | 브라우저, 자동화 도구, 수동 시각 검토 | 자동 검사는 겹침 등 후보 탐지에 유용. 의미와 번역의 판정은 별도 |

시각화 확장과 검수는 **같은 데이터와 같은 결과물 요구**로 한다. 입력 스키마, 의미 유형 커버리지, 편집 가능한 원본, SVG/HTML 출력, 한국어·아랍어 폰트, RTL 방향, 반응형·인쇄, 접근성, 용량·성능을 확인한다. PNG/PDF가 필요한 납품은 실제 출력 파일을 별도로 검증한다.

## 현재 검증 상태

- 내부 HTML/CSS/SVG 경로: [실험 02](../samples/visualization-catalog.html)에 7계열 55개 템플릿과 내부 SVG/HTML 렌더러를 구현했다. 카탈로그의 샘플 데이터 55개를 오류·경고 없이 SVG로 출력하고, 권장 모션 55개 모두에서 브라우저의 실제 애니메이션 대상을 확인했다. 공간 2개 유형은 3D 좌표 투영으로 교체하고 임의 상자 장면을 받는 CLI를 추가했다. [구성 선택 실험](../samples/composition-review.html)에서 3개 와이어프레임·초기/포화·모션 전환을 검수했다. 긴 가상 라벨은 생략 경고가 남는다. 샘플의 통과를 임의 데이터·복잡한 자동 배치의 통과로 해석하지 않는다.
- 외부 프로그램/스킬: 시각화 실행 경로에서 사용하지 않는다. 브라우저는 내부 결과의 실렌더 검수에만 사용한다.

어떤 생성 방식에서도 내부의 A/B/C 합의, 데이터 계약, 다국어 검수, 실제 렌더 검수를 생략하지 않는다.
